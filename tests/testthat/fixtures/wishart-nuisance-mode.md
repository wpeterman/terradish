# Wishart nuisance-mode regression fixture

The matrix pair comes from the existing S1 L03 R2 pooled-seven analysis, actual
coordinates, with Gaussian width 1. It contains only the 60-site graph covariance
`E`, the observed allelic covariance `S`, information parameter `nu = 3000`, and
the formerly retained nuisance estimate. It contains no individual genotypes.

The original nuisance optimizer returned convergence code 0 at both starts but
log likelihoods of -151494.469917915 (fresh) and -151595.12989754 (retained).
The retained log nugget was about -37.44, leaving its derivative negligible
despite a better solution with nugget about 0.1414. The regression requires
identical profiling from these starts and checks derivatives by perturbation.

Source: `analysis/current_version_stabilization_20261019/nuisance_mode_reproducer.rds`
in the manuscript analysis checkout. The fixture copies only `E`, `S`, `nu`, and
`retained_phi`; it was not generated by a new simulation.
